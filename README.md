# C - Sorting algorithms & Big O

This project is about learning different sorting algorithms in C and understanding how Big O notation works to evaluate time complexity.

* Ali Abdulkarim Alhussaini

## Requirements
* Compiled on Ubuntu 20.04 LTS using `gcc`
* Compilation flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
* Code style: Betty style
* No global variables allowed
* Max 5 functions per file

## Files Included

* **sort.h**: Header file containing all function prototypes and the struct for doubly linked lists.
* **0-bubble_sort.c**: Function that sorts an array using Bubble sort algorithm.
* **0-O**: Time complexity of Bubble sort (best, average, worst case).
* **1-insertion_sort_list.c**: Function that sorts a doubly linked list using Insertion sort.
* **1-O**: Time complexity of Insertion sort.
* **2-selection_sort.c**: Function that sorts an array using Selection sort algorithm.
* **2-O**: Time complexity of Selection sort.
* **3-quick_sort.c**: Function that sorts an array using Quick sort (Lomuto partition scheme).
* **3-O**: Time complexity of Quick sort.
* **print_array.c**: Helper function to print arrays.
* **print_list.c**: Helper function to print doubly linked lists.
